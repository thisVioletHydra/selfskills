# portfolio-bento

Bento-сетка резюме/портфолио после OrbitHero.

| Блок | Источник |
|------|----------|
| Sidebar (портрет, bio, контакты) | `fetchProfile()` + `DEMO_RESUME` |
| Stats, experience, education | `profile.facts` + `DEMO_RESUME` |
| Skills / software | `DEMO_RESUME.skills` + `PLANETS` |
| Drives | `profile.goals` |
| Projects | `PROJECTS` |

Потом: GraphQL modules `resume`, `planet`, `project`.
