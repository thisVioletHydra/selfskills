# gateway

404 и 502 — общий layout в `FaultPage.tsx`.

## Как посмотреть (dev)

| Страница | URL |
|----------|-----|
| 404 | http://localhost:5173/404 |
| 404 catch-all | http://localhost:5173/любая-фигня |
| 502 (макет) | http://localhost:5173/502 |

## Как словить по-настоящему

| Страница | Как |
|----------|-----|
| **502** | На главной `/` — убей `pnpm back` (или `pnpm db up`), рефреш. ProfilePage ловит ошибку GraphQL и показывает GatewayPage. |
| **404** | Любой несуществующий path, не `/` и не `/502`. |

Главная `/` — ProfilePage. API упал → 502 на месте, без отдельного URL.
