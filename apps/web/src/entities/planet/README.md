# entities/planet

**Planet** — сущность орбиты: то, что крутится в hero и открывается карточкой.

Контент внутри (стек, вакансии, что угодно) — поля планеты, не отдельное имя сущности.
Если выкинешь планеты — выкинешь и фичу целиком.

- `planets.ts` — `Planet`, `PLANETS`, `CORE_PLANET`, `ORBIT_PLANETS`
- `planet-groups.ts` — группы для списка ниже hero
